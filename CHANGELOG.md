# Changelog

All notable changes to this project will be documented in this file.

## Release 2.1.0

**Features**

- Add explicit coverage for OpenNebula 7.0.x, 7.2.x and 7.4.x releases.
- Add `yumrepo_core` and `cron_core` module dependencies.

**Bugfixes**

- Repair the unit test suite for Puppet 8 and Ruby 3.2.
- Clean up all Puppet lint warnings.
- Fix the `onehost` provider command environment.

**Breaking changes**

- Remove support for OpenNebula 4.x and 5.x.
- Remove the OpenNebula 5.12 configuration templates.
